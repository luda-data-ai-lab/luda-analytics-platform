5. {{ '고급 분석' if ko else 'Advanced analysis' }}

{{ '데이터셋 화면이나 대시보드에서 [고급 분석]을 누르면 표준 분석 방법론 3가지를 컬럼 선택만으로 실행할 수 있습니다. 결과는 차트·표와 함께 문장형 인사이트로 요약됩니다.' if ko else 'Open [Advanced Analysis] from a dataset page or the dashboard to run three standard analytical methods by simply choosing columns. Results come with charts, tables and a written summary.' }}

  • {{ '시계열 분석' if ko else 'Time series' }}: {{ '날짜·값 컬럼과 주기(일/주/월/분기/년)·집계 방식을 고르면 추세선, 이동평균, 전기 대비 증감률(MoM), 전년 동기 대비(YoY), 선형 추세+계절 성분 기반 예측(95% 구간)을 계산합니다.' if ko else 'Pick a date column, a value column, a frequency (daily/weekly/monthly/quarterly/yearly) and an aggregation to get a trend line, moving average, period-over-period (MoM) change, year-over-year change and a linear-trend + seasonality forecast with a 95% band.' }}
  • {{ '이상치 탐지' if ko else 'Outlier detection' }}: {{ 'IQR(기본 1.5배) 또는 Z-score(기본 ±3) 기준으로 정상 범위를 계산해 벗어난 행을 표시하고, 그룹 컬럼을 고르면 그룹별 이상치 건수도 보여 줍니다.' if ko else 'Flags rows outside the normal range using IQR (1.5× by default) or Z-score (±3 by default), and—if you pick a group column—shows how many outliers each group contributes.' }}
  • {{ '상관 · 기여도' if ko else 'Correlation & drivers' }}: {{ '숫자 컬럼 간 상관행렬 히트맵과 상관이 가장 강한 조합을 보여 주고, 타깃 컬럼을 고르면 표준화 회귀계수(β)로 변수별 기여도와 설명력(R²)을 제시합니다.' if ko else 'Shows a correlation heatmap across numeric columns and the strongest pairs; choosing a target column adds standardized regression coefficients (β) per driver plus the model fit (R²).' }}
{{ '해석 시 주의: 예측은 과거 추세가 이어진다고 가정한 단순 모델이므로 단기 참고용입니다. 상관관계와 회귀계수는 인과관계를 보장하지 않으며, 데이터 기간이 짧거나(3기간 미만) 숫자 컬럼이 부족하면 분석이 실행되지 않습니다.' if ko else 'Read with care: the forecast is a simple model that assumes the past trend continues, so use it for short horizons only. Correlation and regression coefficients do not prove causation, and the analysis is skipped when the series is too short (fewer than 3 periods) or there are too few numeric columns.' }}

6. {{ '세그먼트 · 검정 분석과 리포트' if ko else 'Segmentation, testing & reports' }}

{{ '[고급 분석] 화면의 나머지 탭에서는 고객·마케팅 실무에서 많이 쓰는 네 가지 방법론을 실행하고, 결과를 Excel 파일이나 인쇄·PDF 리포트로 내보낼 수 있습니다.' if ko else 'The remaining tabs of [Advanced Analysis] run four methods widely used in customer and marketing work, and every result can be exported to Excel or to a print/PDF report.' }}

  • {{ 'RFM 세그먼트' if ko else 'RFM segmentation' }}: {{ '고객 식별 · 거래일 · 금액 컬럼을 고르면 고객별 최근성(R) · 빈도(F) · 금액(M)을 계산해 1~5점으로 점수화하고, 충성 우수 고객 · 단골 · 신규·성장 가능 · 이탈 위험 · 휴면으로 분류합니다. 점수는 절대 기준이 아니라 업로드한 데이터 내 상대 순위(5분위)입니다. 고객이 3명 미만이면 실행되지 않습니다.' if ko else 'Choose customer, date and monetary columns to score each customer 1-5 on recency (R), frequency (F) and monetary value (M), and to label them Champions, Loyal, Potential, At risk or Hibernating. Scores are quintiles relative to the uploaded data, not absolute thresholds, and the analysis needs at least 3 distinct customers.' }}
  • {{ '파레토 (ABC) 분석' if ko else 'Pareto (ABC) analysis' }}: {{ '분류 컬럼과 값 컬럼을 고르면 분류별 기여도와 누적 비율을 계산해 누적 80%까지를 A, 95%까지를 B, 그 이상을 C 등급으로 나눕니다. 재고·상품·거래처 우선순위를 정할 때 쓰며, 분류가 2개 미만이거나 합계가 0 이하면 실행되지 않습니다.' if ko else 'Pick a category column and a value column to rank contribution and cumulative share, classifying categories as A (up to 80% cumulative), B (up to 95%) or C (above 95%). It is the usual way to prioritise SKUs, products or accounts; it is skipped when there are fewer than 2 categories or the total is zero.' }}
  • {{ '코호트 리텐션' if ko else 'Cohort retention' }}: {{ '고객을 첫 거래 시점(주/월/분기/년)으로 묶어, 이후 경과 기간별 재방문율을 히트맵으로 보여 줍니다. +0 열은 항상 100%이며, 아직 기간이 도래하지 않은 상위(최근) 코호트의 칸은 0%가 아니라 빈칸로 표시되고 평균에서도 제외됩니다.' if ko else 'Groups customers by the period of their first transaction (weekly/monthly/quarterly/yearly) and shows the share that returns in each later period as a heatmap. Column +0 is always 100%, and periods that have not elapsed yet for a recent cohort are left blank rather than shown as 0% and are excluded from averages.' }}
  • {{ 'A/B 유의성 검정' if ko else 'A/B significance test' }}: {{ '그룹 컬럼(A/B)과 지표 컬럼을 고르면 두 그룹의 평균 차이(Welch t-검정) 또는 전환율 차이(비율 z-검정)를 검정해 차이·상승률 · 95% 신뢰구간 · p-value 를 제시합니다. 전환율 모드는 값이 0보다 크면 전환으로 봅니다. p-value 가 0.05 미만이면 "통계적으로 유의하다"고 보지만, 이것은 우연일 가능성이 낮다는 뜻일 뿐 인과관계나 사업적 중요도를 보장하지는 않습니다.' if ko else 'Pick a group column (A/B) and a metric column to compare group means (Welch t-test) or conversion rates (two-proportion z-test), with the difference, lift, 95% confidence interval and p-value. In conversion mode any value greater than 0 counts as a conversion. A p-value below 0.05 is treated as statistically significant, which only means the gap is unlikely to be chance — it does not prove causation or business impact.' }}
  • {{ '리포트 내보내기' if ko else 'Report export' }}: {{ '화면 오른윗쪽 [Excel 내보내기]는 현재 탭의 지표·인사이트 요약과 결과 표를 .xlsx 파일로 받고, [PDF 리포트]는 차트까지 포함된 인쇄용 화면을 열어 브라우저의 “PDF로 저장”으로 보관할 수 있게 합니다. 두 기능 모두 본인 데이터셋에만 사용할 수 있습니다.' if ko else '[Excel export] downloads an .xlsx file with the current tab\'s metrics, insight summary and result tables; [PDF report] opens a print-ready page including the charts so you can use the browser\'s “Save as PDF”. Both are restricted to your own datasets.' }}
{{ '해석 시 주의: RFM · ABC · 코호트 결과는 업로드한 기간과 데이터 범위에 따라 달라집니다. A/B 검정은 그룹 배정이 무작위였을 때만 인과적 해석이 가능하며, 표본이 적으면(그룹당 2건 미만) 실행되지 않습니다. 사용 가능한 그룹이 3개 이상이면 건수가 많은 두 그룹을 자동으로 비교합니다.' if ko else 'Read with care: RFM, ABC and cohort results depend on the period and scope of the uploaded data. An A/B test only supports causal reading when assignment was random, and it is skipped when a group has fewer than 2 rows. If more than two groups exist, the two largest are compared automatically.' }}
