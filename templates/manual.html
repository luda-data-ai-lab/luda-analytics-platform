2. {{ '데이터 업로드' if ko else 'Uploading data' }}

{{ '상단 메뉴의 [업로드]에서 CSV 또는 Excel 파일을 올립니다. 첫 번째 행은 반드시 열 이름(헤더)이어야 합니다.' if ko else 'Use [Upload] in the top menu to add a CSV or Excel file. The first row must contain the column names (header).' }}

  • {{ '권장 구조' if ko else 'Recommended structure' }}: {{ '한 행 = 한 건의 기록, 날짜·수치 열은 빈 칸 없이 일관된 형식으로 입력' if ko else 'one row per record; keep date and numeric columns consistently formatted and free of blanks' }}

{{ '숫자 열에 쉼표(1,000)나 단위(원, %)가 섞여 있으면 문자로 인식되어 차트에 사용할 수 없습니다. 숫자만 남겨 주세요.' if ko else 'If numeric columns contain commas (1,000) or units (%, USD), they are read as text and cannot be charted. Keep digits only.' }}
